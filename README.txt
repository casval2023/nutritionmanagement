栄養計算・食事記録 Ver.3
Windows: python -m pip install -r requirements.txt
その後 start.bat をダブルクリックしてください。

食品本表 2,538食品を data/foods_standard.csv に収録。
アミノ酸・脂肪酸・炭水化物・食物繊維・有機酸の各表もCSVとして同梱（詳細表示の連携は今後の拡張対象）。
独自食品 data/foods_custom.csv、食事履歴 data/meals.csv、明細 data/meal_items.csv に保存。
注意：数値の Tr（微量）、-（未測定等）は欠測扱い。*は注記を取り除いて数値として扱います。
食品成分表は可食部100g当たり。購入重量と可食部重量は区別してください。
公式の元データを参照し、調理状態（生、ゆで等）を正しく選択してください。
栄養計算は概算であり、疾病治療用の栄養管理にそのまま使用しないでください。
CSVはローカル単独利用向けです。複数人同時書込には非対応です。
